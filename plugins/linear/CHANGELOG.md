# 更新日志

## 0.5.0（未发布）

- 按规则回写时只改指派给你的事项：事项改派给别人后不再改它的状态。需要更新后的 Antumi。

## 0.4.0

- 「设置 → 集成 → Linear → 回写」可直接选 In Progress、Done，也能自己填。
- 要配合更新后的 Antumi 才按平台显示；旧版 Antumi 照旧是三个文本框，规则照常生效。

## 0.3.1

- Antumi 里不再看不到 Linear 的回写设置和任务详情里的回写区块（0.3.0 的安装包漏了回写声明）。

## 0.3.0

- 支持回写：在 Antumi 里修改 Linear 事项状态、发评论（API Key 需要 Write 权限）。

## 0.1.0

- 支持从 Linear 同步事项、导入任务及重新拉取描述和评论，可按团队、项目和指派人筛选。
