# 更新日志

## 0.4.0（未发布）

- 「设置 → 集成 → 禅道 → 回写」改为从禅道能做的操作里选，不再显示发不出去的评论选项。
- 要配合更新后的 Antumi 才按平台显示；旧版 Antumi 照旧是三个文本框，规则照常生效。

## 0.3.1

- Antumi 里不再看不到禅道的回写设置和任务详情里的回写区块（0.3.0 的安装包漏了回写声明）。

## 0.3.0

- 支持回写：在 Antumi 里流转禅道任务、Bug、需求的状态（账号要有对应动作的权限），状态改用禅道里的中文名称；暂不支持写评论。
- 同步任务时由禅道直接筛出指派给自己或未完成的任务，任务很多的执行不再同步超时；账号无权查看时提示缺权限。

## 0.1.0

- 支持通过禅道 REST API v1 同步任务、Bug 和需求，并导入原文快照。
