# 更新记录

## 1.6.0

- 按规则回写时只改分配给你的事项：事项交给别人（如测试）后不再改它的状态。需要更新后的 Antumi。
- 「改状态」不再列出要填必填字段（如解决结果）的转换，选了也只会失败；这类转换仍需到 Jira 里操作。

## 1.5.0

- 「设置 → 集成 → Jira → 回写」可直接选 In Progress、Done 等常用状态，也能自己填状态名或转换名。
- 要配合更新后的 Antumi 才按平台显示；旧版 Antumi 照旧是三个文本框，规则照常生效。

## 1.4.1

- Antumi 里不再看不到 Jira 的回写设置和任务详情里的回写区块（1.4.0 的安装包漏了回写声明）。

## 1.4.0

- 支持回写：在 Antumi 里修改 Jira 事项的状态、发评论（需要有写权限的 API token）。

## 1.3.0

- 把新评论交给 Agent 时，评论里贴的图片会一起带过去（需要支持评论图片的 Antumi）。

## 1.2.1

- 问题的附件图片都已带到 Antumi 时，不再多出「附件需要登录 Jira 查看」；只有没带过来的附件才提示去 Jira 看。

## 1.1.0

- 在 Antumi 里排查 Jira 问题时，先交出正文让 Agent 开始，附件图片随后再拉，网络慢时不再卡住。需要 SDK 0.1.2。

## 1.0.0

- Jira 从 Antumi 内置来源迁移为独立插件，保留邮箱与 API token 登录、JQL 同步、正文、评论和图片附件导入。
