# 更新日志

## 0.3.0（未发布）

- 「设置 → 集成 → 飞书项目 → 回写」提示节点流的写法和不防倒退的限制。
- 要配合更新后的 Antumi 才按平台显示；旧版 Antumi 照旧是三个文本框，规则照常生效。

## 0.2.1

- Antumi 里不再看不到飞书项目的回写设置和任务详情里的回写区块（0.2.0 的安装包漏了回写声明）。

## 0.2.0

- 支持回写：在 Antumi 里修改工作项状态（状态流的下一状态、节点流完成当前节点）、发评论（需要勾选「允许创建或修改数据信息」的 MCP Token）。

## 0.1.1

- 空间里没有「归档」字段时不再同步失败，默认筛选条件改为我参与的工作项；空间没有优先级字段时也能同步。
- 筛选条件用了空间里没有的字段时，提示会写出是哪个字段。

## 0.1.0

- 支持通过飞书项目 / Meegle 的 MCP Token 同步一个空间的工作项，并导入详情和最近评论。
